# 工作英语 · 每天 20 分钟

跨境电商 / TikTok 投放场景的英语刷题 App。词和句子全部来自你飞书里的真实沟通。

双击 **启动学习.command** 开始。学完关掉黑窗口即可，进度已存。

---

## 新词和复习是分开的

首页三个按钮，**复习在最上面**：

```
先复习 · N 词     ← 到期的词，正卡在遗忘边缘
学新词 · N 词     ← 随时学都行
短语模块 · XXX
```

建议顺序就是从上到下。到期的词晚一天成本高得多，新词没这个问题。
两边队列完全独立，做一半退出来也不会互相串。

## 复习按遗忘曲线排

复习队列的顺序不是随机、也不是按加入时间，而是：

1. **顽固词排最前** —— 它们最需要
2. 其余按 **「此刻还记得多少」升序** —— 最快要忘的先出

「还记得多少」是 FSRS 用你这个词的 stability 和距上次复习的天数算出来的留存概率，
刷题时进度条旁边会显示（`记得 87%`）。这就是遗忘曲线本身，不是我估的。

## 经常做错 vs 偶尔做错

分三档，首页和统计页都看得到：

| 档 | 判定 | 待遇 |
|---|---|---|
| **顽固** | 错过 3 次以上，或错 2 次且 FSRS 判定难度高 | 每次复习排最前 |
| **偶尔错** | 错过 1-2 次 | 正常排序 |
| **干净** | 一次没错过 | 正常排序 |

统计页「经常做错 vs 偶尔做错」那一节列出具体是哪些词，每个词后面的小数字是**错过几次**，
点一下直接开释义弹窗。刷题时进度条旁边也会标当前这个词属于哪一档。

⚠️ 一个技术细节：判定用的是我自己数的错误次数，**不是 FSRS 的 `card.lapses`**。
实测连续答错 5 次 lapses 还是 0 —— FSRS 只把「学会之后又忘」算作 lapse，
学习阶段答错不算。所以那个字段在这里没用。

## 一轮里同一个词最多问 3 次

真不会的词，硬磨没用。问够 3 次还没对就先放过，结束页会告诉你放过了哪些，
明天让 FSRS 按曲线重新安排。

（不设这个上限的话会卡死：答错就重排进队列，一直答错就永远结束不了这一轮。实测过。）

## 一个词怎么算「会」

要**连续答对 3 次**，而且三次考法不同、由浅到深：

| 关卡 | 考什么 | 怎么答 |
|---|---|---|
| 第 1 关 · 认词 | 能不能认出来 | 英文 → 四选一中文 |
| 第 2 关 · 盲猜 | 有上下文能不能想起来 | 只给一句挖空的例句 → 认识 / 模糊 / 不认识 |
| 第 3 关 · 说出来 | 能不能主动产出 | 只给中文 → 出声说英文 → 说对了 / 没说对 |

任何一关失手，连对次数**清零**，从第 1 关重来。卡片右上角三个小圆点就是进度。

**默认一天最多推进一关。** 所以连对 3 次至少横跨 3 天 —— 这才算真的记住了。
想快可以在设置里关掉，同一次学习就能连过三关，但那只是连点三下。

另外：三关没过完之前，复习间隔最多压到 2 天内。
原因是第 1 关只测「认得出」，答得快 FSRS 会排到 5-9 天后；
但第 3 关测的是「说得出」，是另一种能力，不该因为认得快就推迟九天再考。
满 3 次之后解除限制，交给 FSRS 正常拉长间隔。

## 发音

**默认用系统合成音（Samantha 美音）**，不是真人录音。

真人录音（60 个词，Wikimedia 志愿者录的）还在，但**默认不用**：那些录音口音很杂，
英音、印度音、澳音都有，练发音反而是干扰。想听的话两个入口：
- 设置 → 发音用哪个音源 → 切「真人录音」
- 单词弹窗里点「🔊 真人」单听一次

系统语音里那 40 多个「英语语音」有一半是音效（Bahh / Boing / Zarvox），已经过滤，
下拉里只剩 22 个能正常读词的。语速可调。

一点声音都没有的话：系统设置 › 辅助功能 › 朗读内容 › 系统声音，下载一个英语声音。

## 双击单词

弹窗里有：音标、真人/合成发音按钮、**分词性的多个释义**（v. / n. / adj. 分开列）、
注释、你的原话例句、**举一反三**、当前熟练度。

「举一反三」是 392 条扩展用法，包括：
- 同根词变形：`refund` (n. 重音在前) vs `refund` (v. 重音在后)
- 常见搭配：`align on something`（介词固定用 on）
- 易混对比：`return` = 货回来 ｜ `refund` = 钱回去
- 踩坑提醒：说 PPT 老外多数听不懂，要说 deck

## 双击句子里任意一个词

单词卡的例句、短语模块的句子、第 2 关的挖空句 —— 里面**每个词都能双击**，
弹出中文释义 + 音标 + 发音 + 「加入生词本」。

背后是一份从 [ECDICT](https://github.com/skywind3000/ECDICT) 抽出来的词典，
只抽了本 App 928 句里实际出现的 **933 个词，覆盖 100%**，打包 95 KB，不联网。
变形词会自动找原形（`added` → `add`）。

顺手解决了一个烦人的事：句子上加了 `user-select:none`，
双击不会再选中文字，Chrome 自带的划词菜单和 Grammarly 那个弹窗不会再冒出来盖住卡片。

## 生词本

首页「生词本」进去。任何地方双击一个词，弹窗里点「＋ 加入生词本」就存进来。
单词卡的弹窗里也有这个按钮。

生词本每行显示：单词、音标、释义、**当初是在哪句话里遇到的**、加入日期。
点 🔊 发音，点 ✕ 移出。

释义是**渲染时实时查词典的**，不是存死的快照 —— 词典以后改好了，生词本里自动跟着好。

## 词库页

首页「词库」可以按分类翻全部 158 个词，每行显示音标、中文、有没有真人录音、熟练度圆点。
点任意一行打开完整释义弹窗。

## 进度会不会丢

三重保险：浏览器 localStorage + 每隔几秒备份到 `backups/worken/` + 启动时自动比对恢复。
`server.py` 有一道保护：**空进度不允许覆盖非空备份**。
设置页还有「导出到文件」。

## 要加词

编辑 `js/data-words.js`（基本字段）和 `js/data-extra.js`（音标 / 多词性 / 举一反三）。
`cat` 必须是 `window.CATS` 里已有的键，否则出不了同类干扰项。
`js/data-audio.js` 是自动生成的，别手改。

改完把 `index.html` 里对应的 `?v=` 数字 +1，否则浏览器吃缓存。

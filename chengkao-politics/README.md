# 成考专升本政治 · AI 私教刷题 App

一个运行在电脑上、可离线刷题、联网后带 AI 私教功能的网页学习 App，用来备考
**全国各类成人高等学校招生考试 · 专升本 · 政治**。

> 目标：满分 150，考到 **90 分以上（60%）**。设计理念是「**宁可题少而懂，不要题多而糊**」——
> 每道题都逐个选项讲清楚，不懂还能追问 AI，直到你说懂。

---

## 一、怎么打开

**方法 A（最简单）**：直接双击 `index.html`，用 Safari 或 Chrome 打开即可。
没网也能用：刷题、看解析、错题本、打卡、摸底测试全部照常，只有 AI 功能会提示「需要联网」。

**方法 B（推荐，避免个别浏览器限制）**：在这个文件夹里开一个本地小服务器：
```bash
cd "成考政治AI私教"
python3 -m http.server 8000
```
然后浏览器打开 `http://localhost:8000`。

---

## 二、第一次使用：先摸底，再定计划

1. 打开后先填**考试日期**和**每天学习时长**（可选填 API Key）。
2. 点「开始摸底测试」——系统从题库里按模块、按难度抽一套题给你做。
3. 做完出一份**诊断报告**：各模块正确率、粗估卷面分、最弱模块，并自动生成
   **三阶段学习计划**（打地基 → 全面铺开 → 刷卷冲刺）。
4. 之后每天点「开始今日训练」即可，App 会自动搭配：新知识点 + 到期复习的旧题。

想重做摸底：设置 →「重做摸底测试」（刷题进度会保留）。

---

## 三、填 API Key（解锁 AI 功能）

1. 到 [console.anthropic.com](https://console.anthropic.com) 注册并创建一个 API Key（形如 `sk-ant-...`）。
2. 打开 App →「设置」→ 粘贴到 **Claude API Key** → 保存。
3. Key 只存在你本地浏览器（localStorage），不会上传到任何服务器。

**模型选择**（设置里可改）：
- 讲解等日常轻活：默认 `claude-haiku-4-5-20251001`（便宜、快）。
- 批改 / 诊断等重活：默认 `claude-sonnet-5`（更强）。
- 如果官方模型名有更新，以 [docs.claude.com](https://docs.claude.com) 为准，直接在设置里改字符串即可。

**AI 功能一览**：
1. 逐题「讲到懂」：每题答完点「让 AI 再讲一遍」，逐项分析 + 口诀 + 可追问。
2. 主观题批改：辨析/简答/论述，写完 AI 估分、指出漏掉的采分点、给满分参考答案。
3. 错题诊断报告：找出你反复错的知识点模式，生成个性化小课。
4. 背诵陪练：就某考点提问、听你复述、纠正补全。
5. 按需出题：针对薄弱考点「再来 5 道类似的」。
6. 每日教练：首页根据进度给一句今日重点。

> 没填 Key 也完全能用：所有基础刷题、解析、错题本、模拟考照常，只是上面 6 个 AI 功能会提示需要 Key。

## 四、怎么自己加题

题库在 **`js/questions.js`**。它本质就是一个 JSON 数组，只是外面包了一句
`window.QUESTION_BANK = [ ... ]`（这样双击 `index.html` 也能读到；用纯 `.json` 会被浏览器安全策略拦截）。

加题：复制文件里任意一道题，改内容，放进数组即可。字段说明：

| 字段 | 说明 |
|---|---|
| `id` | 唯一编号，别重复，如 `"phi-031"` |
| `module` | 大模块：`马哲` / `毛中特` / `时政` |
| `chapter` | 小章节，如 `"唯物论"` |
| `topic` | 细考点标签（用于薄弱点统计、间隔复习） |
| `type` | `single` 单选 / `multiple` 多选 / `辨析` / `简答` / `论述` |
| `difficulty` | 难度 `1` 易 / `2` 中 / `3` 难 |
| `stem` | 题干 |
| `options` | 选项数组（主观题写 `[]`） |
| `answer` | 单选=正确项下标(0起)；多选=下标数组如 `[0,2]`；主观题=参考答案文本 |
| `explanation` | 整体解析（大白话说考什么） |
| `optionNotes` | 逐项说明，每项以「对：」或「错：」开头（主观题写 `[]`） |
| `keyPoints` | 采分点数组（主观题用；客观题写 `[]`） |

单选题示例：
```js
{
  id: "phi-031", module: "马哲", chapter: "认识论", topic: "实践标准",
  type: "single", difficulty: 2,
  stem: "检验真理的唯一标准是",
  options: ["逻辑推理", "社会实践", "多数人意见", "权威判断"],
  answer: 1,
  explanation: "真理对不对，不能光靠嘴说，得拿到实践里去检验。",
  optionNotes: ["错：逻辑只能自圆其说，不能最终检验。","对：社会实践是检验真理的唯一标准。","错：人多不代表对。","错：权威也会错。"],
  keyPoints: []
}
```

改完保存文件，刷新页面即可生效。也可以用 App 里「AI 出题」生成新题，再复制进这个文件永久保存。

## 五、改考试日期

- 快捷：App →「设置」→ 修改「考试日期 EXAM_DATE」→ 保存。
- 首次引导页也能填。默认 `2026-10-17`，**以官方公布为准**。

## 六、导出 / 导入存档（换电脑、备份）

- **导出**：设置 →「导出存档」，下载一个 JSON 文件，包含进度、错题本、打卡、主观题历史等全部数据。
- **导入**：设置 →「导入存档」，选中之前导出的 JSON 即可恢复。

所有数据默认存在浏览器 localStorage；清空浏览器数据或换浏览器会丢，所以重要节点记得导出备份。

## 九、拿分策略（重要，别死磕难题）

试卷 150 分 = 选择题 80 + 辨析 20 + 简答 30 + 论述 20。对基础薄弱、平时上班的人，最优路线是：

1. **选择题拿稳 55+**：考点固定、反复考"母题"，用本 App 刷到条件反射。这是主战场。
2. **主观题靠背模板拿 35+**：辨析/简答/论述共 70 分是"送分区"——阅卷松，往采分点上靠、分点写，写多少给多少。背熟"判断+理由框架""采分点骨架"即可。
3. **55 + 35 = 90，稳过线。** 别在偏难怪题上耗时间。

首页有「🎯 90分怎么拿？」卡片随时可看。

## 十、工作日 / 周末双节奏

针对"周一到五上班效率低、周末有空"：

- **工作日**：自动切「轻量模式」（默认 15 分钟，约 8 题），以快速复习选择题、保持手感为主。
- **周末**：自动切「冲刺模式」（默认 40 分钟，约 22 题），上新知识点，并**自动加练 1 道主观题**（辨析/简答/论述按日期轮换）。

App 会根据"今天是工作日还是周末"自动切换，首页和训练页都会提示当前模式。两个时长都可在「设置」里改。

## 十一、v2 新增：系统化学习

- **白话概念扫盲层（零基础地基）**：每章先给「白话概念卡」，用生活例子解释术语（如"矛盾＝既对着干又离不开的两方""共性＝共同点、个性＝各自特点""寓于＝藏在里面"），看懂词再背要点再做题。内容在 `js/curriculum.js` 的 `primer` 字段。
- **难度真正分层（先易后难）**：阶段1「打地基」只出**易题**（含入门概念题 `js/questions-basic.js`），不会一上来撞难题；阶段2出中等题；阶段3出全部+主观题。某阶段该难度全章掌握后**自动升级**下一阶段。
- **系统学习主线**：按考纲 15 章顺序（唯物论→…→时政）一章章攻克，每日"三步走"：先看懂关键词 → 再读必背卡 → 再练**这一章**的题（题目与当天概念紧密对应，不再东拼西凑）。首页显示"正在攻克：第X章"。
- **每日必背模块**：每章一张必背卡（固定表述+核心考点+口诀），是选择题和主观题的命根子，每天读一遍、可标记"已背"。内容在 `js/curriculum.js`，可自己增删。
- **专项练习模块（不重复轮次）**：选模块/章节/押题，一次 10/20/30 题。**做过的本轮不再出现，中途退出再进接着做**；整轮做完自动进入下一轮。
- **学习进度页**：每章「一次性通关率」（第一次做就对的比例）判断掌握度（未学/学习中/已掌握）+ 每日/累计学习时长 + 近 7 天时长图。
- **每日学习时长统计**：答题/背诵时自动计时，首页和进度页可见。
- **每日 AI 学习总结**：练完 AI 总结今天表现、薄弱点、明日重点。
- **AI 助手升级**：背诵陪练 / AI 出题 / **AI 押题** / **章节串讲**（系统讲整章）/ **AI 答疑**（随便问）。
- **押题库**：`js/questions-yati.js`，高频押题，可在专项练习里"只刷押题"。
- **背 / 懂 标注**：每道题标了 <strong>🧠 靠背</strong>（记固定表述）还是 <strong>💡 懂原理</strong>（理解后能套用），答完还给一句针对性学习提示。规则：辨析题=懂、简答论述=背采分点、客观题按人工核定的"应用题清单"判断；想改某题的标注，在题库里给它加 `learn:"背"` 或 `learn:"懂"` 即可（见 `js/questions.js` 文件头说明）。

# 成考专升本英语

这个文件夹里现在有**两套**界面，共用同一批题库：

| 打开哪个 | 是什么 | 什么时候用 |
|---|---|---|
| **`index.html`** ← 默认 | **应试策略台（新版）** | 目标 70 分过线。按板块记分、固定答题顺序、错题必须归因、只学 7 大语法考点 |
| `旧版-完整版.html` | 老版 AI 私教（28 章主线） | 想按章节系统学、用一条龙每日流程时 |

两边**进度分开存**，互不影响（localStorage 键不同，硬盘备份也分目录）。

---

## 策略台（新版）怎么用

一句话：**首页那张「板块记分牌」就是全部**。它只回答一个问题——每个板块现在几分、离目标差几分。

- 全部规则写在 **`js/strategy.js`** 一个文件里（目标分、板块权重、答题顺序、7 大考点、写作模板、对话场景、阅读套路、生词标准）。改策略只改这个文件，界面会跟着变。
- 三条硬规矩，别改回去：
  1. **错题不选归因不许进下一题**（VOCAB / SYNTAX / TRAP / TIME）——不归因就不知道该补词汇、补句法还是补套路
  2. **模考按固定顺序**：补全对话 → 写作 → 语法 → 阅读 → 完形 → 语音，板块之间不能往回跳
  3. **不做总进度条、不做打卡徽章、不让 AI 生成模拟题、不给推断题和态度题做专项**
- 语音 5 分：模考里自动全涂 C，不花时间（策略规定的零投入板块）。
- 生词：**只收真题里影响解题的词**，两个队列（认出即可 / 必须会拼）互不相通。在阅读题里双击单词就能收。

文件结构：`strategy.js`（策略）→ `core.js`（存档/分数/题库索引）→ `api.js`（AI）→ `ui.js`（界面）。

## 老版说明（以下内容对应 `旧版-完整版.html`）

一个跑在你自己电脑上、可联网、带 AI 私教功能的网页版英语学习 App，
专为备考「全国各类成人高等学校招生考试 · 专升本英语」而做。

> 核心目标不是刷题量，而是 **让你真正理解每一道题**：
> 每道题都把 4 个选项逐一讲清（对的为什么对、错的各错在哪），
> 全部用简单中文（A2 / 新概念1 水平也看得懂），看不懂还能一直追问 AI。

---

## 一、怎么打开（最简单）

1. 找到桌面上的文件夹 **「成考英语AI私教」**。
2. 双击里面的 **`index.html`**，它会用你的默认浏览器（Safari / Chrome）打开。
3. 就能用了 ✅

- **不填 API Key 也能用**的功能：刷题、看解析、背写作模板、挖空默写、错题本、模拟考。
- **需要填 API Key（联网）**的功能：AI 讲题、追问、作文批改、错题诊断、对话陪练、AI 出题、每日教练。
- 没网时，AI 功能会自动提示"需要联网"，其它功能照常用。

> 提示：如果个别浏览器对本地文件比较严格，把整个文件夹拖进浏览器窗口，或用 Chrome 打开，一般都没问题。

---

## 二、怎么填 API Key（开启 AI 功能）

1. 打开 App → 右上角进【设置】。
2. 去 **console.anthropic.com** 申请一个 API Key（相关文档见 **docs.claude.com**）。
3. 把 Key（`sk-ant-...` 开头）粘进「Anthropic API Key」框，点空白处即自动保存。
4. 点【测试连接】，看到「✓ 连接成功」就 OK 了。

- Key 只存在**你自己浏览器的 localStorage** 里，不会上传到任何其它地方。
- 模型可在设置里换：
  - **日常快速模型**（逐题讲解 / 对话 / 出题）：默认 `claude-haiku-4-5-20251001`（便宜快）。
  - **强力模型**（作文批改 / 错题诊断）：默认 `claude-sonnet-5`（更准）。
  - 模型名以 **docs.claude.com** 为准，随时可改。

## 三、怎么加题 / 改题

题库分两个文件，都是 JSON 数组，随便往哪个加都行：
- **`js/questions.js`** —— 初始题库（真题 + 核心考点）
- **`js/questions-more.js`** —— 扩充题库（阶梯难度，格式一样，会自动接到主题库后面）

它其实就是一个 JSON 数组，
外面包了一层 `window.QUESTIONS = ` —— 这是为了让你**双击打开**时浏览器也能加载
（纯 `.json` 文件在 `file://` 下会被浏览器安全策略挡住，所以放进 `.js`）。

用任意文本编辑器打开，照着已有的题往数组里加就行。每题字段：

```js
{
  id: "gram-999",              // 唯一编号，别重复
  level: 2,                    // 难度：1 入门 / 2 进阶 / 3 冲刺（不写默认按 2）。App 会先易后难安排
  module: "grammar",           // grammar | collocation | cloze | reading | conversation | phonetics
  topic: "subjunctive",        // 知识点标签（用于间隔复习和薄弱点统计）
  stem: "It is important that enough money ____ to fund the project.",
  options: ["be collected", "must be collected", "is collected", "can be collected"],
  answer: 0,                   // 正确选项下标：0=A, 1=B, 2=C, 3=D
  explanation: "整体解析：大白话说这题考什么 + 规则",
  optionNotes: [               // 逐项说明，长度必须 == 选项数
    "对：虚拟语气 (should)+动词原形，should 省略",
    "错：多余的 must",
    "错：用了陈述语气 is",
    "错：多余的 can"
  ],
  // 阅读/完形题可加下面两行（同一篇短文用同一个 passageId，短文会显示在题干上方）：
  // passageId: "rd1",
  // passage: "这里是短文……"
}
```

改完存盘，刷新浏览器即可生效。

> 另外，App 里【练习】页有「🤖 AI 按需出题」：输入知识点让 AI 现场出 5 道新题，
> 可一键「存入题库」（存进你的存档，不改动 `questions.js`）。

讲解卡、写作模板、对话场景在 **`js/content.js`** 里，同样可自行增改。

## 四、怎么改考试日期

考试日期是常量 `EXAM_DATE`，两种改法：

- **推荐**：App 内【设置】→「考试日期」直接改（会自动保存）。
- 或改代码默认值：`js/storage.js` 里 `examDate: "2026-10-17"`。

> 默认 2026-10-17（10 月第三个周末），**具体日期以你所在省教育考试院公布为准**。

## 五、怎么导出 / 导入存档（备份）

进度、错题本、打卡、作文历史都存在浏览器本地。换浏览器或想备份时：

- 【设置】→「⬇️ 导出存档」：把全部数据存成一个 JSON 文件下载到本地。
- 【设置】→「⬆️ 导入存档」：选之前导出的 JSON 文件，即可恢复。

> 换电脑、清缓存前记得先导出，否则本地进度可能丢失。

## 六、学习计划（App 会据此排今日任务）

- **阶段一（第 1–4 周）打地基**：写作 3 套模板 + 会话套路 + 核心语法「虚拟语气」。
- **阶段二（第 5–9 周）铺开**：其余语法 + 固定搭配 + 完形技巧 + 阅读策略。
- **阶段三（第 10–13 周）冲刺**：模拟考反复做 + 主攻错题本 + 背熟范文。

阶段可在【设置】里手动切换。首页有倒计时、打卡、进度、AI 每日教练。

### 一句话用法
**第一次用**：首页点【开始摸底 →】做 15 道摸底测试，系统会定位你的水平、自动配好难度和阶段。
之后每天点【开始今日训练】→ 看讲解卡 → 做题（先易后难）→ 每道错题都点「让 AI 再讲一遍」直到懂 →
坚持打卡 → 每周做一次模拟考看提分曲线。宁可题少而懂，不要题多而糊。

### 难度阶梯
每道题标了 `level`：**1 入门 / 2 进阶 / 3 冲刺**。App 会先喂入门题建立信心，掌握后再往上；
阶段一不会出冲刺题。你也可以在【练习】页直接选某个难度专练。

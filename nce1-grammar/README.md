# nce1-grammar · 新概念英语 1 语法练习

两个单页面：

| 文件 | 是什么 |
|---|---|
| `现在完成时-答题.html` | **练习页**（入口）。按新概念 1 的课次组织语法练习，一题一屏、即时反馈，错题进「今日错题」视图 |
| `英语学习手册-v8.0.html` | **语法速查手册**。整册语法按剑桥语法体系整理成 cheatsheet，练习时随手翻 |

## 打开

双击 `启动学习.command`。它会跑 `server.py`（端口钉死 **8902**，不会自动换端口）并打开浏览器。

## 进度备份

网页每次点「提交」都会把进度 POST 给 `server.py`，落到 `backups/`：

- `latest.json` — 最新一份，启动时自动恢复用的就是它
- `backup-YYYYMMDD-HHMMSS.json` — 历史快照，只保留最近若干份

`backups/` 不进仓库。空进度不会覆盖已有的好备份。

## 改 UI 时怎么验证

不要在 8902 端口上点题（会把真实进度弄脏）。把目录复制一份到临时位置，用另一个端口（如 8903）起服务验证，验证完再把改动合回来。

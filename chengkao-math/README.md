# 成考高数 AI 私教 · 专升本高等数学(二)

一个跑在 Mac 上、可离线、带 AI 私教的网页版高数学习 App，专为
**「全国各类成人高考 · 专升本 · 高等数学(二)（经管类）」** 备考设计。
面向"初二数学水平、高数从 0 开始、目标 60+ 分"的学习者。

---

## 一、怎么打开（重要：用启动器，别双击 index.html）

**双击 `启动高数App.command`** —— 它用本地小服务器(localhost:8011)打开 App。
第一次可能提示"无法验证开发者"：右键 →「打开」→ 再点「打开」即可（只需一次）。

> ⚠️ **为什么不直接双击 `index.html`？** 直接开是 `file://`，浏览器更新/清缓存时容易把进度清掉，而且和 `localhost` 是两套存储、进度对不上。**以后固定用启动器打开**，进度最稳。

- 没网也能用：刷题、看分步解析、背公式、看进度都不需要联网。
- AI 功能（讲题 / 批改 / 诊断 / 出题）需要联网 + 填一次 API Key。

## 一·五、自动备份（进度不怕丢）

- **双写备份**：每次存档同时写主存档 + 一份备份键；万一主存档被浏览器清空，下次打开**自动从备份恢复**（且空进度不会覆盖好备份）。
- **备份提醒**：好几天没导出时，首页会弹"一键备份"，点一下把进度导出成 JSON 存到硬盘。
- **换电脑/重装**：设置 →「💾 存档」导出，到新机器导入即可。
> 建议每隔几天点一次"一键备份"，最保险。

## 一·六、开局：先摸底 → 拿到你的「提分计划」

第一次打开会**先做摸底测水平**（十几道题，从最简单到难，不计分）。做完自动给你：
- **起点定位**（零基础启蒙 / 预备 / 基础 / 冲刺）
- **目标 60 分 · 最省时路线**：选择填空吃满 → ⭐核心必考(极限/导数/积分/导数应用)练熟 → 难证明题先放
- **专属闯关路线**：从你的起点章开始，标出哪些是核心、哪些过一遍即可
（纯小白也可以点"直接从第 1 课学"跳过摸底。）

## 二、填 API Key（B.AI 中转，和你英语 App 用同一个 key）

1. 打开 App → 右上角 **⚙️ 设置**。
2. 在「🤖 AI 接口」里，**只需填 API Key**（其它已默认配好）：
   - 接口地址 `apiBase`：`https://api.b.ai`
   - 接口格式：`Anthropic 原生`
   - 日常模型：`claude-haiku-4-5`；强力模型：`claude-sonnet-5`
3. 点「测试连接」，显示 ✅ 即可。

**Key 怎么来**：去 `chat.b.ai` 注册、创建 API Key，用支付宝/微信充值。
一个 key 两个 App（英语 / 高数）通用，各填一次即可。

> ⚠️ 安全：API Key 只保存在你本机浏览器的 localStorage 里，**不要贴给任何人、不要发到聊天里**。

### 遇到"网络请求失败 / CORS"怎么办
浏览器直连有时会被 CORS 拦。到设置把「接口格式」切成 **OpenAI 兼容**
（会改用 `/v1/chat/completions` + `Authorization: Bearer`），多数中转两种都支持。
仍不行就联系 B.AI 客服确认是否支持浏览器直连。

## 三、功能一览

- **📘 从零开始 · 数学扫盲（重点）**：给"连字母、根号、次方都忘了"的同学。9 节大白话小课（`lessons.js`），从"$x$ 是什么"讲起：字母表示数 → 正负数 → 分数小数 → 次方 → 根号 → 运算顺序 → 代入求值 → 解方程 → 认识函数。每节读完做 2 道小题即算过。首页第一张卡就是入口，第一次打开也默认推荐从这里学。配套 21 道 level 0「启蒙」题（生活化、超简单）。
- **🗺️ 学习地图（在「进度」页）**：按大纲顺序的 9 章（扫盲→预备→极限→导数→导数应用→积分…→概率），标出"当前章 / 下一章"和每章通关率。今日主攻的知识点自动锁定在"当前章里练得最少的"，不再东一榔头西一棒子。
- **📝 白话概念卡（离线，不靠 AI）**：预备~冲刺的每个知识点（极限、导数、积分、偏导、拐点…共 16 个，`concepts.js`）都有一张大白话概念卡，先讲"这个词啥意思、生活比方"，再练题。断网也能看。
- **📖该背 / 🧠该懂 标记**：每道题都标出是"靠记公式"还是"靠想通思路"，帮你分配精力。
- **难度兜底**：启蒙/预备阶段的每日"解答题"只出该阶段难度（level ≤ 1/2），**绝不会**把 level 4 真题证明扔给零基础的你；另加了 7 道循序渐进的解答题（代入、解方程、基础求导积分）。
- **🏠 首页 = 一个大按钮**：打开就一句"跟着学就行" + 一个「▶ 开始今日学习」。点下去自动一步步带你走完（学概念→做题→背公式→弱点专练→解答题），每步之间只有一个"继续 →"，**中途不回首页、不用你做选择**，走完弹"🎉今天完成啦"。首页不再堆一堆卡片。
- **今日学习**：按你设定的 20/40/60 分钟自动配量、自动选今天学哪个知识点（锁定"当前章里练得最少的"），你只管点"开始"跟着走。
- **摸底测试**：跨难度小卷，做完把你定位到"预备夯实期 / 基础攻坚期 / 冲刺期"，可让 AI 出详细计划。
- **练习**：按难度（预备/基础/提升/冲刺）或按知识点专练；做过的排后面。
- **背公式**：翻卡 + 间隔复习（记得的隔久点、不会的天天见），掌握率并入进度。
- **学习进度**：每个板块/知识点的"一次性通关率"彩色条 + 公式掌握率。
- **错题本**：做错自动收集，可只刷错题，可生成 AI 诊断报告。
- **模拟考**：快速小考 / 按真题结构整卷模拟。
- **AI 功能**：逐题"再讲一遍"(可追问)、"换个说法再考我"、解答题批改、错题诊断、按薄弱点出题、每日教练/小结。

## 四、自己加题（`questions.js`）

打开 `questions.js`，在 `window.QUESTIONS = [ ... ]` 里照葫芦画瓢加。每题字段：

| 字段 | 说明 |
|---|---|
| `id` | 唯一编号（别和已有重复） |
| `module` | 板块：`prep`预备 / `limit`极限与连续 / `derivative`导数与微分 / `application`导数应用 / `integral_indef`不定积分 / `integral_def`定积分 / `multivar`多元微分 / `probability`概率 |
| `topic` | 知识点标签（用于复习和薄弱点统计，如"导数计算""极限计算"） |
| `level` | 0启蒙(扫盲) / 1预备 / 2基础 / 3提升 / 4冲刺 |
| `type` | `choice`选择 / `fill`填空 / `solve`解答 |
| `stem` | 题干，公式用 `$...$`（行内）或 `$$...$$`（居中）包起来 |
| `options` | 选项数组（仅 choice），也用 `$...$` |
| `answer` | choice：正确下标(0~3)；fill：可接受答案数组 `['1/2','0.5']` |
| `explanation` | 大白话整体思路 |
| `steps` | 分步解题过程数组（solve 必填，其它建议有） |
| `optionNotes` | choice 四个选项逐项说明，长度=选项数 |

**LaTeX 小抄**：分数 `\dfrac{a}{b}`、根号 `\sqrt{x}`、次方 `x^{2}`、下标 `x_{1}`、
积分 `\int_{a}^{b}`、极限 `\lim_{x\to0}`、求导用 `f'(x)`（JS 里写成 `f\'(x)`）、
希腊字母 `\pi \alpha`、无穷 `\infty`。
> JS 字符串里反斜杠要写两个：`\\dfrac`、`\\sqrt`。单引号里的撇号要转义：`f\'(x)`。

**填空判分**做了宽松归一化（忽略空格、`1/2`≈`0.5`、`x^2`≈`x²`、去掉结尾 `+C` 等）。
拿不准就在 `answer` 里多放几种写法。

## 五、加公式（`formulas.js`）

`window.FORMULAS = [ ... ]`，每张卡：

| 字段 | 说明 |
|---|---|
| `id` | 唯一编号 |
| `group` | 分组：导数 / 积分 / 极限 / 三角 / 函数 / 多元 / 概率 |
| `name` | 卡片正面的中文提示（如"x 的 n 次方的导数"） |
| `latex` | 卡片背面的公式（**不用**加 `$`，程序会自动包） |
| `example` | 一个小例子（可用 `$...$`） |
| `level` | 难度 1~4 |

## 五·五、加扫盲课 / 概念卡

- `lessons.js`（`window.LESSONS`）：零基础扫盲读本。每节 `{id, topic, title, body:[...], checks:[...]}`，`body` 块用 `{h:小标题}|{p:段落}|{eg:例子}|{tip:提示}`，段落里 `$...$` 是公式、`**文字**` 是加粗。
- `concepts.js`（`window.CONCEPTS`）：白话概念卡，按 `topic` 匹配（和题目 topic 对应）。结构同 `body`。想给某知识点补讲解，往这里加一条即可，做题的"学概念"页会自动显示。

## 六、改考试日期

设置 → 「考试日期」。默认 `2026-10-17`，**以你所在省教育考试院公布为准**。

## 七、导出 / 导入存档

设置 → 「💾 存档」：
- **导出存档**：下载一个 JSON，换电脑/换浏览器时备份。
- **导入存档**：选择之前导出的 JSON 恢复。
- **清空进度**：只清学习数据，设置（含 API Key）保留。

所有进度、错题、打卡、学习时长、公式熟练度都存在浏览器 localStorage。
**换浏览器或清缓存会丢，记得定期导出。**

## 八、关于 KaTeX（公式渲染）

`katex/` 文件夹是本地打包的 KaTeX（`katex.min.js` + `katex.min.css` + `fonts/` 里的 woff2 字体），
**不走 CDN**，所以 `file://` 双击打开、断网也能正确显示公式。不要删除或移动这个文件夹。
